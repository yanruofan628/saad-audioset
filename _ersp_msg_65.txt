## 0. 共同准备

### 数据与时间轴

| 项目 | 建议值 |
|------|--------|
| 采样率 | 250 Hz |
| 单试次长度 | 5 s（1250 点）若与现稿一致 |
| 刺激 onset | **相对试次起点 3.0 s**（样本索引 `750`） |
| ERP 窗 | **−0.2 ~ +2.0 s**（相对刺激 onset） |
| ERSP 窗 | **−0.2 ~ +2.0 s**，基线 **−0.2 ~ 0 s** |
| 参考/滤波 | 与论文预处理一致（CAR、0.1–40 Hz 等） |

### 从 `npy` 做成 MNE Epochs（刺激 onset = 0）

```python
import numpy as np
import mne

sfreq = 250.0
stim_onset_s = 3.0          # 相对 5 s 试次起点
pre_s, post_s = 0.2, 2.0   # 刺激锁定窗

# X: (n_epochs, n_channels, n_times=1250), 来自 processed/*_eeg.npy
start = int((stim_onset_s - pre_s) * sfreq)
stop = int((stim_onset_s + post_s) * sfreq)
X_lock = X[:, :, start:stop]   # (n_epo, n_ch, n_samp)

tmin = -pre_s
info = mne.create_info(ch_names=ch_names, sfreq=sfreq, ch_types="eeg")
montage = mne.channels.make_standard_montage("GSN-HydroCel-128")  # 或你们的 cap
info.set_montage(montage, on_missing="ignore")

epochs = mne.EpochsArray(
    X_lock * 1e-6,  # 若 npy 是 µV；若是 V 则去掉 *1e-6
    info,
    tmin=tmin,
    event_id={"dichotic": 1},
    baseline=(-pre_s, 0),  # ERP/ERSP 基线
)
epochs.set_eeg_reference("average")
```

> **更严谨**：从 **raw `.mff` + 事件标记** 重新 `mne.Epochs(events, tmin=-0.2, tmax=2.0)`，避免 trial-end 对齐误差。有事件码时优先这条。

## 1. 刺激锁定 ERP（替代主文 3e/3f 的主图）

### 要画什么

- **(a)** 组平均 ERP：Fz 或 Cz（听觉）  
- **(b)** 峰值时刻 **地形图**（如 N1 约 80–120 ms）  
- 可选：**(c)** 全脑 butterfly（补充）

### 步骤

```python
# 1) 每人 evoked，再 grand average
evokeds = []
for sub in subjects:
    ep = load_subject_epochs(sub)  # 上节 EpochsArray
    evokeds.append(ep.average())

grand = mne.grand_average(evokeds, weights="equal")  # 或 mne.combine_evoked

# 2) 波形图
fig = grand.plot(picks=["FZ", "Cz"], spatial_colors=False, time_unit="s")

# 3) 地形图：找通道均值峰值时间
picks_topo = mne.pick_types(grand.info, eeg=True, exclude="bads")
data = grand.get_data(picks_topo)
times = grand.times
peak_t = times[np.argmax(np.abs(data).mean(axis=0))]  # 或固定 t=0.1

grand.plot_topomap(times=[0.08, 0.12, peak_t], ch_type="eeg")
```

### 图形要点

- 纵轴 µV，横轴 ms（`times * 1000`）  
- 竖线 0 = dichotic onset  
- 图注：**baseline −200~0 ms, stimulus-locked**  
- 正文写：**auditory evoked responses**，不写 selective attention  

### 探索性（可选）

```python
left_epochs = epochs[labels == "left"]
right_epochs = epochs[labels == "right"]
mne.viz.plot_compare_evokeds(
    {"reported left": left_epochs.average(), "reported right": right_epochs.average()},
    picks="eeg", combine="mean",
)
# 严谨：cluster permutation（mne.stats.spatio_temporal_cluster_test）
```

## 2. 刺激锁定 ERSP / 时频（比 3e 更合适）

### 要画什么

- 一张 **time × frequency** 热图（组平均）  
- 常用 **4–30 Hz**，**dB 相对基线**

### 步骤（Morlet，MNE 标准）

```python
freqs = np.arange(4, 31, 1)
n_cycles = freqs / 2.0   # 或 freqs * 0.25，低频周期别太短

power = mne.time_frequency.tfr_morlet(
    epochs,
    freqs=freqs,
    n_cycles=n_cycles,
    average=True,           # 先组内平均再组间，或先全部再平均
    return_itc=False,
    decim=2,                # 可选，加速
    n_jobs=1,
)

# 组平均：对每个被试 average=True 得到 power 再 grand
# 若 epochs 已是所有人合并，average=True 即 grand

power.plot(
    picks=["Cz", "Fz"],
    baseline=(-0.2, 0),
    mode="logratio",        # 或 "percent" → 即 ERSP/ERSP 常用 dB
    vmin=-1, vmax=1,
    cmap="RdBu_r",
)
```

### 全脑均值 ERSP（一张总图）

```python
# 所有 EEG 通道平均后的 TFR
power_all = power.copy().pick(picks="eeg")
data = power_all.data.mean(axis=0)  # (n_freq, n_times)
import matplotlib.pyplot as plt
plt.imshow(
    10 * np.log10(data / data[:, :,(power.times < 0)].mean(-1, keepdims=True)),  # 简化
    aspect="auto",
    origin="lower",
    extent=[power.times[0], power.times[-1], freqs[0], freqs[-1]],
)
plt.axvline(0, color="k")
plt.xlabel("Time (s)"); plt.ylabel("Frequency (Hz)")
```

更省事：`power.plot_topo(baseline=(-0.2, 0), mode="logratio", tmin=0, tmax=2)`

### 与旧 PSD(3e) 的差别（画图时）

| 旧 3e | ERSP |
|-------|------|
| 对 **0–3 s 静** 与 **3–5 s 有声** 各算 **一条 PSD 曲线** | 对每个试次、**以 onset=0** 算 **功率随时间变化** |
| `psd_welch` 在长静段上 | `tfr_morlet` + `baseline=(-0.2,0)` |

## 7. 常见坑

1. **npy 单位**：µV 还是 V，进 MNE 要一致。  
2. **只用 3–5 s 段且 tmin=0**：那是 **刺激起点为 epoch 起点**，不是刺激锁定；应用上面 **slice + tmin=−0.2**。  
3. **ERSP n_cycles**：<4 Hz 时周期数 ≥5，避免不稳定。  
4. **先剔除坏试次** 再 grand average，与解码一致。
