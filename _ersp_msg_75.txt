不一定只画单电极，但**主文通常 1–2 个代表电极 + 可选一张 topo** 就够。

---

## 整段 2 s ERSP 可以怎么画

| 画法 | 适用 | 主文？ |
|------|------|--------|
| **单电极**（如 Cz 或 Fz） | 最清楚，一张 time×freq 热图 | **推荐主图** |
| **2–4 个电极子图**（Cz, Fz, T7, T8） | 双耳分听可看颞区 | 补充或 composite |
| **全脑电极平均** 后一条 ERSP | 组水平总趋势 | 可以，但丢空间信息 |
| **多个 topo**（固定频率/时间） | 看空间分布 | 补充，不必主文 |

**不是** 128 张单导 ERSP 全放进主文。

---

## 推荐组合（与 2 s 刺激一致）

**时间窗：** 刺激锁定 **−0.2 ~ +2.0 s**（覆盖整段 dichotic）  
**频率：** 例如 **4–30 Hz**（或 2–40 Hz）  
**基线：** **−0.2 ~ 0 s**，`mode='logratio'` 或 `'percent'`

### 主文（最简单）

```
一张图：(a) Cz 的 ERSP，全试次 grand average
可选 (b)：N1 附近某时刻的 topo，或 alpha 频段某时间窗的 topo
```

### 代码思路（MNE）

```python
power = mne.time_frequency.tfr_morlet(
    epochs, freqs=np.arange(4, 31, 1), n_cycles=freqs / 2,
    average=True, return_itc=False, decim=2,
)
# 单电极
power.plot(picks=["Cz"], baseline=(-0.2, 0), mode="logratio", vmin=-1, vmax=1)

# 或多电极
power.plot(picks=["Cz", "Fz", "T7", "T8"], baseline=(-0.2, 0), mode="logratio")
```

## 要不要分选左/选右？

与 ERP 一样：

| 用途 | 建议 |
|------|------|
| **Validation（主图）** | **全试次**，不分 L/R |
| **探索** | 可各画一张 Cz ERSP 或差值图（L−R），放补充 |

---

## 和“整段 2 s”的关系

- **横轴 0~2 s** = 刺激播放期（+ 前 0.2 s 基线）  
- 说明 **刺激后功率如何随时间变**，不是“注意触发时刻”  
- **单电极 Cz** 已能说明 **事件相关时频合理**；不必 128 导各画一张  

---

## 一句话

**整段 2 s ERSP：主文画单电极（Cz，可选加 Fz/T7/T8）即可；也可多电极子图或加 topo，不必只限单电极但也不必全脑每张。** 验证用 **全试次、不分左右** 最稳。
